# Laboratório de Estruturas de Dados e Algoritmos — UFCG

Roteiros e atividades práticas da disciplina de Laboratório de Estruturas de Dados e Algoritmos (LEDA), UFCG, em Java.

## Conteúdo

| Roteiro | Tema |
|---|---|
| R01 | Ordenação simples — Bubble, Insertion, Selection Sort (e variações) |
| R02 | Ordenação recursiva — Merge Sort, Quick Sort (com mediana de três) |
| R03 | Insertion Sort recursivo |
| R04 | Ordenação linear — Counting Sort |
| R05 | Busca binária — floor/ceil |
| R07 | TADs lineares — Pilha e Fila (implementação própria) |
| R08 | Listas encadeadas — simples, dupla e recursiva |
| R10 | Tabela hash — endereçamento aberto e fechado, com múltiplas funções de hash |

Cada roteiro é um módulo Maven independente, com implementação em `src/main/java` e testes em `src/test/java`.

## Como executar os testes de um roteiro

```bash
cd R01-01-Rot
mvn test
```
